# 🎺 UKM Marching Band USU Schedule Analyzer

## 📌 Deskripsi Proyek
Proyek ini dibuat untuk membantu mengatasi permasalahan penjadwalan latihan pada **UKM Marching Band Universitas Sumatera Utara (MB USU)**.

Sebagai UKM tingkat universitas, anggota MB USU berasal dari berbagai fakultas dengan jadwal kuliah yang berbeda-beda. Hal ini menyebabkan:
- Sulit menentukan waktu latihan yang optimal
- Banyak bentrok jadwal antar anggota
- Koordinasi menjadi tidak efisien

💡 **Solusi yang ditawarkan:**  
Aplikasi ini menganalisis jadwal anggota dan memberikan insight terkait waktu terbaik untuk kegiatan UKM.

---

## 🚀 Fitur Utama
- 📊 Analisis jadwal anggota dari berbagai fakultas  
- ⏰ Identifikasi waktu kosong terbanyak  
- 📈 Visualisasi data menggunakan dashboard interaktif  
- 🧠 Membantu pengambilan keputusan jadwal latihan yang optimal
